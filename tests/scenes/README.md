# Тестовые сцены

Маленькие сцены, написанные руками. Каждая проходит `validate.py --strict`, и каждая остаётся тестом навсегда.

| Файл | Что проверяет |
|---|---|
| `kub.json` | первый образец Никиты (куб 50 мм), как есть |
| `box_in_world.json` | коробка 100×50×20 с центром в (10, 20, 30), без поворота |
| `nested_boxes.json` | железная вставка 100×50×20 внутри бетонного блока 400×300×200, `parent`, без поворотов |
| `rotated_box.json` | коробка 20×40×70 в (300, −150, 80), поворот 90° вокруг z через углы Эйлера |

Ожидаемые значения в `verification` посчитаны вручную:

- `box_in_world`: объём 100·50·20 = 100 000 мм³, bbox = центр ± половины размеров.
- `nested_boxes`: bbox вставки дан в системе блока (родителя): центр (50, −30, 10) ± (50, 25, 10).
- `rotated_box`: поворот на 90° вокруг z переводит локальную ось x в мировую y, а y в −x, поэтому в мире размеры по x и y меняются местами: 40 × 20 × 70, bbox = (300, −150, 80) ± (20, 10, 35).
